# 知途设计规范

## 设计方向与理由

采用「行动工作台」：暖灰画布、白色内容面、深墨文字、克制的常青绿操作色。平台需要多年持续使用，阅读、训练记录和管理编辑都需要密集而清楚的信息，而非大幅营销介绍。空间图标与辅助色只用于识别；按钮、表单、焦点、错误和确认继续使用同一个平台体系。

平台首页先呈现今天真实的未完成安排（最多5项），之后是已加入空间的紧凑摘要、继续最近业务内容与设置下一步。全部任务页显示包括已完成在内的真实安排，支持按空间与处理状态筛选。任务是读取视图，进入原业务目标执行，不增加一键完成按钮，不改写空间完成规则。

## 导航与布局

- 平台：首页 / 今日任务 / 空间目录；账号菜单提供设置和 ADMIN 管理工作台。
- 空间：统一切换面板，有收藏、最近3次访问与可搜索的个人入口；全量目录单独进入。顶栏最多显示2个收藏快捷入口。
- 空间内部：由模块注册自己的导航；课程内部保留阅读、知识、练习、真题、笔记、手册。加入、收藏、隐藏与退出仅整理入口。
- 首页用行动列表与双列摘要；目录在宽屏3列、中屏2列、手机1列，搜索和筛选始终可见。
- 阅读沿用内容型工作区：可展开目录、阅读阶段与下一项；默认正文16px，行高1.85。
- 健身今天先展示训练与食谱，再展示快速录入和记录摘要。训练、饮食使用其业务组件；编辑使用独立页面，轻量数据用弹窗。
- 管理员独立框架，桌面使用管理任务导航和工作区域；手机使用任务选择器。管理不挂载自学周期与课程上下文。
- 手机底部只有首页 / 今日 / 空间 / 更多。内部功能在更多面板或空间自己的页面中，不把全部空间堆进横向菜单。

## 基础规则

| 项目 | 规范 |
|---|---|
| 平台画布 | #f5f6f3 |
| 主文字 | #202d2a |
| 次要文字 | #56635e |
| 主操作 | #345d57，悬停 #22443f |
| 边界 | #dbe1dc |
| 自学辅助色 | #4667ab |
| 健身辅助色 | #277763 |
| 普通说明 | 14–16px；正文16px |
| 页面标题 | 桌面28px / 手机25px |
| 内容面圆角 | 12–14px；按钮7px |
| 触控目标 | 表单、按钮与导航至少44px高 |
| 焦点 | 3px蓝色可见边框，3px偏移；页面变化聚焦main-content |

布局宽度主要1240px，管理1440px；列使用minmax(0,1fr)，长文字允许换行。局部数学公式与表格可以在自己的容器滚动，禁止整页横向滚动。

## 状态与交互

每个空间摘要单独加载、报错和重试。没有任务时显示继续内容与计划设置入口；所有空间失败时明确显示失败，不当作所有任务已完成。未上线空间显示「即将开放」，无加入、进度或业务按钮。

表单保存中防止重复写入，原版本冲突与幂等规则不变。统一UnsavedChangesProvider收集多个表单的未保存状态，拦截路由离开，取消保留输入，确认只丢弃未保存修改。弹窗捕获焦点、Esc关闭并恢复触发按钮；优先焦点用data-autofocus而非原生autoFocus，避免破坏焦点恢复。
