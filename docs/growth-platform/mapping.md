# 现有功能 → 平台与空间入口

实际项目：frontend（React 18 / Router 6 / React Query / Vite），backend（Spring Boot 3 / Java 17 / MySQL / Flyway）。两者是独立 Git 仓库。本次基于已有未提交题库、批改与健身工作继续，未重置仓库。

| 现有功能 | 新入口 | 保留的数据 / 规则 |
|---|---|---|
| 个人首页 /personal/summary | / 今日行动，/today 跨空间任务 | 按空间独立读取原业务接口，避免串联故障 |
| 学习总览 /study | 自学 → 今日 | 当前周期、今日建议、真实进度 |
| 科目、目录、知识、实践手册 | 自学 → 课程 → 课程内部页 | 阅读进度、章节与知识内容 |
| 学习计划、备注 | 自学 → 计划 / 笔记 | 原计划与备注规则 |
| 练习、题库、检测、检测结果 | 自学 → 练习与检测 | 原题库、提交、完成与解锁规则 |
| 真题、成绩、图片答卷批改 | 自学 → 课程 → 真题与成绩 | 原答卷、成绩版本、批改状态与权限 |
| 健身今天、训练、食谱、体重、目标、历史、模板 | 健身 → 对应内部入口 | 所有本人记录、版本、统计与幂等规则 |
| 管理员工作台 | 平台账号菜单 → 管理工作台 | 独立布局，原 ADMIN 双端守卫 |
| 账号设置 | 平台 → 账号设置 | 统一账号与原个人资料 |
| /zikao/** | /study/** | 查询参数、锚点原样跳转 |
| 无 | /spaces 空间目录与空间切换弹层 | 本人加入、收藏、顺序、隐藏、最近访问持久化 |

可信目录由后端配置决定。上线空间仍通过原业务接口鉴权；未上线空间无业务路由、任务或进度。加入/隐藏仅控制个人入口，绝不删除空间业务数据。
