# 学习知途 · 学习书桌产品重构

## 项目与保留边界

真实前端是 `repo/frontend`，拥有独立 Git 仓库；React 18、TypeScript、Vite 8、React Router、TanStack Query。后端是 `repo/backend`，Spring Boot / Java 17，MySQL 来自既有开发 Compose 服务。阅读了项目说明、OpenAPI、业务规则和联调说明，并启动旧站检查真实页面与数据。

本次重建面向学习用户的导航、页面布局、设计系统与状态呈现。保留生成的接口客户端、身份认证、权限检查、检测答案队列、幂等写入和修订冲突处理；检测门槛与账号权限保持原规则。后续用户明确授权扩展计划排期，后端计划服务和兼容旧记录的约束更新见文末。健康检查、组件演示和已有管理员占位路由保留为内部入口，不出现在学习导航中。

学习进度、练习尝试、知识掌握程度、检测资格、纸卷成绩、正式成绩各自独立。实践科目只提供实际支持的能力；未提供自动图片批改、虚构薄弱点统计或假模拟卷。

## 三个设计方向

| 方向 | 视觉与布局 | 排版、颜色、密度 | 学习与长期使用影响 |
| --- | --- | --- | --- |
| 学习书桌（采用） | 横向任务导航；首页为下一项与今日清单；课程是书架；目录与当前学习项并置；知识展开为正文阅读；作答为独立题面 | 纸白、墨绿、细分隔；界面中文无衬线，阅读与题干中文衬线；中等偏紧的信息密度 | 日常行动明确，适合长时间阅读；目录和正文有各自位置，练习时收起非必要工具 |
| 专注路径 | 窄导航与单步骤工作区；一次只呈现一个任务；完成后进入下一步；过程状态集中显示 | 深色框架、明亮题面、较少同时可见信息；统一无衬线 | 上手简单、减少分心；跨科比较、检索与计划调整需要更多切换 |
| 知识索引 | 编辑式标题和密集检索；课程、章节、知识点围绕搜索与表格；首页以索引和最近记录组织 | 黑白与小范围信号色；清晰编号、紧凑行距、较高密度 | 熟练用户查找很快；初次备考时不容易知道今天应先做什么 |

选择学习书桌：该产品同时服务“今天做什么”和“持续读下去”，任务清单与阅读版式比极端单步骤或纯索引更平衡。布局按任务变化，不要求全站使用相同卡片骨架。代表页面的实际截图位于 `redesign-evidence/home-desktop.jpg`、`knowledge-desktop.jpg`、`practice-desktop.jpg`，手机证据见相同目录。

## 新信息架构与任务出口

主导航仅保留：**今日 / 学习 / 练习与检测 / 计划 / 笔记**。知识、手册、真题和成绩属于具体课程；新建练习与检测总入口帮助跨科选择。原有课程代码、章节、条目、题目、检测会话与笔记深链接继续解析。

| 页面 | 主要任务与入口 | 主要操作 | 完成后的去向 |
| --- | --- | --- | --- |
| 登录 | 进入本人学习空间，保留原目标地址 | 校验输入、登录、提交反馈 | 原目标页或今日 |
| 今日 | 判断下一步；登录/主导航进入 | 直接打开建议任务或上次位置；真实今日任务完成操作 | 当前学习项、周计划、课程 |
| 学习书架 | 选择课程及对应内容 | 阅读/知识/手册/练习/真题入口；报考与正式成绩；有权限时编辑考试安排 | 对应课程工作区 |
| 阅读与进度 | 从任务、目录或上次位置继续 | 选择章节与条目、打开真实资料、完成并继续、取消完成、确认批量完成 | 下一未完成项、知识索引、课程笔记或今日 |
| 知识索引 | 搜索并理解一个知识模块 | 搜索/难度筛选；展开正文、公式、例题、资源；保存掌握程度与笔记 | 返回保留筛选与位置的模块列表、相关课程内容 |
| 实践手册 | 连续阅读与实际动手 | 手册搜索、目录定位、代码复制、实际章节练习完成记录 | 下一章节、课程目录、课程笔记 |
| 练习与检测入口 | 选科、确定训练目的 | 章节刷题/真题变种/错题重做/检测；按真实题数和资格进入 | 专注作答或检测规则确认 |
| 练习 | 作答并理解解析 | 答案选择→提交→正确性与解析→继续；收藏、不确定、快速笔记 | 下一题、错题重做、章节范围 |
| 检测 | 有规则地检验掌握 | 资格与规则确认→真实申请→计时、题号导航、答案自动保存→检查漏答→交卷 | 成绩、错误题解析、薄弱点（仅实际结果提供）与继续练习 |
| 真题与成绩 | 找试卷、记录成绩照片、理解趋势 | 三个独立视图：找真题/成绩与照片/趋势与分析；下载、手动录入、上传真实照片、编辑记录 | 成绩记录、趋势、下一轮练习 |
| 计划 | 执行本周、处理逾期与容量 | 新建范围/优先级/每日时间；周次导航、完成任务、逾期详情、顺延预览与确认 | 今日任务、对应学习内容、调整后的计划 |
| 笔记 | 记录并回到内容 | 科目/标签/搜索；新建、编辑、删除确认、快速记录、回到课程内容 | 关联知识/阅读/练习或笔记列表 |

## 核心流程与真实规则

- 阅读完成写入稳定条目 ID 和修订号，服务端确认后选择下一未完成条目。没有资料的条目明确说明，不创建假下载。
- 练习按真实范围选题，提交返回正确答案和解析；练习次数不会被当作阅读完成。错题、收藏、不确定仍使用本人状态。
- 章节检测保留原题审核、练习资格和策略条件。模拟申请使用真实 `applyAssessment` 与幂等键；开始后服务端时间持续推进，网络异常提示未同步，交卷基于已保存答案。
- 真题下载和成绩写入使用实际权限。临考跳过仍走明确确认；不能借此授权检测。答题照片用于记录，成绩人工录入，保持私有文件授权及格式/大小校验。
- 正式成绩与缴费状态新增清晰入口，保留乐观锁和未知值；“正式通过但没有分数”不会被伪造为60分。
- 新计划不覆盖旧计划，范围、课程优先级、每一天容量交给原计划接口。日期未知保持待确认；容量不足明确拒绝或由用户选择接受未排入。
- 顺延保留先预览后确认，使用计划修订与预览指纹；不私自挪动未来安排。任务完成仍反映真实目录条目状态。
- 笔记编辑保留草稿、保存反馈、冲突提示与知识模块切换时的保存语义。

| 容器 | 任务台用行清单和阅读主区；书架用水平课程条目；知识按索引→正文；计划用周次导航→每日安排；检测用题面与题号面板 |

状态设计：加载放在所属区域；空状态说明下一步；局部错误允许重试且不拖垮整页；无权限说明原因与学习路径；禁用展示门槛；保存成功使用明确状态；修订冲突回滚乐观呈现并保留可恢复草稿；重复提交锁与幂等业务保护继续生效。

手机端重排：今日先行动再清单与日历；课程条目垂直展开；目录按需打开；知识采用单列正文；计划使用横向周次选择；作答操作固定在底部导航上方。练习/检测快速笔记入口移至内容顶部，避免遮挡答案。长公式、表格、代码不造成整页横向溢出。

## 运行

项目根目录 `repo`：

```sh
docker compose --env-file .env.integration -p xuexizhitu-dev up -d --wait
./scripts/start-backend-dev.sh
```

`repo/frontend`（Node 22.12+ / 22.x）：

```sh
npm ci
npm run dev
```

前端 `http://127.0.0.1:5173`；后端 `http://127.0.0.1:8080`。Vite `/api` 代理到后端，`VITE_API_MOCK=false`。沿用用户当前本地数据库配置，不在交付文件保存密码。后端脚本需要已有构建产物；干净环境先按照 backend README 构建。

生产产物通过 `npm run build` 生成 `dist`。部署沿用现有同源 `/api` 反向代理与 SPA 路由回退；本次未向公网发布。

前端分支 `redesign/study-desk`。先把用户原有四个文件修改保存为提交 `7a10f1d`，并额外存放补丁和源文件备份于 `/private/tmp/xuexi-redesign-backup`。既有 `.DS_Store`、IDE元数据未纳入改动；实施期间新增的原界面截图提交 `b935806` 也已保留，没有重写历史。

需要查看重构前状态，可在独立目录检出 `7a10f1d`；该点包括用户原有修改。回退交付时使用 `git revert` 撤销后续重构提交，避免丢失后来的工作。前端版本回退不会改动数据库或本人学习记录。

## 五周计划与当前计划编辑

用户追加授权扩展后端排期，要求保留原计划和学习记录。

- 新增 WEEKLY_35 策略：开始日计作第1天，共35天，前4个7日窗口各安排一门理论课，第5个7日窗口集中真题与复习。容量不足保持待安排，不跨科挤占下一周；考试截止日期继续有效。
- 当前计划可修改名称、开始日期、范围/科目順序、每日时间和排期方式。五周模式自动计算第35天结束日；连续模式可独立修改结束日。
- 每天容量可设0–1440整数分钟；0为休息日；可批量设置后单日微调。移动开始日按第几天保留容量。
- 修改先通过原预览接口提交完整config，确认使用修订号和指纹并检查实际进度、课程发布版本、考试日期与日期变化。未确认不会替换当前计划。
- 确认生成新版本，历史安排和任务范围保留，未删除旧任务、目录进度或用户数据；历史安排只读，完成状态仍展示真实学习记录。
- 没有已发布真题/复习模板的科目增加独立计划复习任务，估时60分钟，跳转现有练习入口；不生成试卷、模拟结果或自动批改。V7仅放宽REVIEW任务的模板约束，不修改已发布课程内容。
- “进入学习目录”改为紧凑入口，始终位于折叠组外；完成后可以回到内容复习。

验证：235项前端测试、28项后端单元测试和13项独立MySQL接口测试；类型检查、构建、代码检查、接口校验快照一致性通过。真实浏览器检查配置预览、容量0/150、容量缺口、完成组入口、390px手机布局。真实账号验证只生成预览，未替用户接受时间缺口或保存测试配置。

修改入口：计划 → 编辑当前计划 → 调整配置/逐日时间 → 预览修改与重排 → 确认保存新版本。旧版本通过“计划版本”切换。
