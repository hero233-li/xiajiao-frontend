## 设计与任务路径

采用“任务桌面”：墨蓝全局空间导航，蓝色学习、绿色健身、紫色管理。阅读以正文与下一步为中心；健身以日期、就地记录、计划与实际对照为中心；管理以版本状态、内容分区和列表为中心。没有固定全站侧栏。

| 真实任务         | 基线路径/负担                                              | 改版路径与改善                                                  |
| ---------------- | ---------------------------------------------------------- | --------------------------------------------------------------- |
| 无今日安排       | 首页→计划页→再次点新建                                     | 首页“安排学习”直接打开配置，少一次操作                          |
| 进入具体学习目标 | 已有正确目标链接，但被通用空间入口与导航围绕               | 保持一键直达，学习行动成为独立主区；无需记住科目、章节或条目 ID |
| 今日体重或饮水   | 已有就地录入，但页面标题、状态与记录分散                   | 日期和状态在顶部，快速录入紧随其后；饮水增加 250ml 为一键写入   |
| 阅读/手册        | 固定目录占用宽度，手机大纲与内容争空间                     | 目录按需展开，长文和作答使用内容宽度；代码/表格局部滚动         |
| 管理内容编辑     | 版本状态、操作、分区混在同一页流中；已发布内容连浏览也禁用 | 版本操作条＋内容索引＋编辑工作区；只禁修改，检索与翻页仍可用    |
| 真题查找         | 来源课程、年份、月份多层嵌套                               | 按试卷日期排序的清单，来源资料直接在对应行标注                  |
| 复杂模板编辑     | 长表单弹层，返回上下文不明确                               | 独立编辑页面，保留日期、返回入口及离开保护                      |

首次使用验证了无安排配置、目标空状态、笔记空列表及模板库入口；日常重复验证了学习完成、体重/饮水/打卡、计划与实际分开；错误恢复验证了历史失败、真实并发冲突、未保存离开与删除取消。

## 真实流程结果

- 首页：无安排直接打开配置；副本中取消当天条目“1-13.直线与直线平行”完成后，首页指向 `00023/catalog` 的真实 `chapterId` 和 `itemId`，一键打开；完成后进度恢复为 61/87。

- 历史故障：临时本地代理只将历史查询置为 503，其余请求转发真实后端；体重保存仍成功，刷新仍显示 72.4kg。故障代理只用于验收，不进入产品实现。
- 并发冲突：另一个页面更新体重后，旧页面保存 72.5kg 被后端拒绝；输入保留，可点击“读取最新记录，保留输入”读到 72.4kg，再自行核对决定下一步。没有静默覆盖。
- 训练：从计划复制后状态空、动作未勾选；明确选择部分完成，实际 2组×12次与计划 3组×12次分别保存。

- 删除：打开明确指出日期与记录类型的统一确认弹层，取消后实际饮食仍在。
- 管理：副本建立 v4 草稿、写入 REVIEW 任务、保存、校验通过（7章/87条目/148考点/1202题），并在本地副本确认启用 v4；原数据库仍未改变；取消未保存离开后输入保留；已发布 v3 的题库可翻至第2/25页，修改按钮仍禁用。

- 长内容：Java 手册含27个代码块；知识详情含16处公式；手机内容可阅读且页面未整体横向溢出。
