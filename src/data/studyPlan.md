## 1. C++ 程序设计（04737）

### 1.1 试卷结构（大纲原文）

- 闭卷笔试，**150 分钟**
- 考核层次分值比例：**识记 20% ＋ 领会 35% ＋ 简单应用 30% ＋ 综合应用 15%**
  → 也就是说 **55% 是概念题，40 分左右真需要写代码**
- 难度四档比例：容易 2 : 中等 3 : 较难 3 : 难 2
- 题型五类：单项选择 / 填空 / 程序填充 / 程序分析 / 程序设计

**结论：这不是一门"会不会编程"的课，是一门"读得懂 C++ 代码"的课。** 选择题和程序分析题占大头，靠读书 + 读代码就能拿；程序设计题只占一部分。

### 1.2 九章节奏（教材页码）

| 章 | 内容 | 教材页 | 核心考核点 | 权重判断 |
|---|---|---|---|---|
| 1 | C++ 语言简介 | 29–56 | 与 C 的差异、命名空间、输入输出初识、编译过程 | 低 |
| 2 | 面向对象基本概念 | 61–90 | 类/对象/封装/继承/多态的定义与区分、成员访问控制 | 中（概念题大户） |
| 3 | 类和对象进阶 | 91–149 | 构造函数与析构函数、**拷贝构造函数**、**常成员与常引用**、**this 指针**、静态成员、友元、**封闭类** | **最高** |
| 4 | 运算符重载 | 150–176 | 重载规则、成员/非成员重载、常用运算符（+ - [ ] = <<） | 高 |
| 5 | 类的继承与派生 | 177–243 | 派生类构造/析构顺序、继承方式差异、**基于基类设计派生类** | **最高** |
| 6 | 多态与虚函数 | 244–275 | **虚函数与多态的三个条件**、纯虚函数与抽象类、虚析构 | **最高** |
| 7 | 输入输出流 | 276–301 | 流类体系、格式化控制（setw/setprecision/fixed） | 中 |
| 8 | 文件操作 | 302–328 | 文件流打开模式、读写、定位 | 中 |
| 9 | 函数模板与类模板 | 329–352 | 模板定义、模板特化、STL 基本容器认知 | 高 |

大纲自标难点（这些地方必多花时间）：常量成员与常引用成员、封闭类、this 指针、深浅拷贝、基于基类设计派生类、多态成立的条件。

### 1.3 每章四步法

1. **先看大纲**（教材 p7–30）该章的「考核要求」，把标着**简单应用 / 综合应用**的条目抄到纸上——只有这些要会写代码，其余认识就行
2. **读教材，例题亲手敲进编辑器跑通**（跑不通 = 没懂）
3. **做课后习题**，对附录答案
4. **合上书自检**：口头回答该章「识记 / 领会」条目，答不出就重读

### 1.4 时间线

| 时间 | 章节 | 强度 |
|---|---|---|
| 2026-11 ~ 12 | 第 1–3 章 | 2h/周 |
| 2027-01 ~ 02 | 第 4–6 章 | 3h/周 |
| 2027-03 | 第 7–9 章 + 第一轮真题 | 5h/周 |
| 2027-03-25 ~ 04-10 | 真题二刷 + 错题 | 独占冲刺 |

### 1.5 真题策略

可用真题（2019 年 4 月起对应现大纲，共 13 套）：2019-04 / 2020-08 / 2020-10 / 2021-04 / 2021-10 / 2022-04 / 2022-10 / 2023-04 / 2023-10 / 2024-04 / 2024-10 / 2025-04 / 2025-10

两轮打法：

- **一轮（按章拆）**：学完一章，把历年真题里该章的题挑出来做。这一步在 3 月前完成
- **二轮（整套限时）**：3/25 起，150 分钟整卷，做 2023–2025 的 6 套，做完立刻对答案、把错的记进错题本

### 1.6 实践（04738，2 学分）

官方给了 10 个实验题目：IDE 使用 / 类定义 / 多文件编程 / 完善类 / 运算符重载（复数乘法）/ 交通工具继承 / 多态 / 格式化 IO / 文件读写排序 / 模板排序 + 链表

- 至少做 6 个，**笔试前完成实验，笔试后择时在主考院校考**
- 提交物：源程序正文 + 实验报告 + 运行结果
- 现在就顺手做前三章对应的实验（类定义 / 多文件 / 完善类），不要等考完理论

### 1.7 自检卡（能不能过考试的硬指标）

- [ ] 能默写一个带构造、析构、拷贝构造、常成员的类
- [ ] 能说清「什么时候必须写拷贝构造」的三种场景
- [ ] 能写虚函数实现多态，并说出多态成立的三个条件
- [ ] 能重载 `+` 和 `<<`，区分成员/非成员
- [ ] 能写出函数模板和类模板各一个
- [ ] 能看懂一段程序并说出输出（程序分析题）
- [ ] 真题整卷稳定 ≥70 分（60 及格）

## 2. Java 语言程序设计（13215）

### 2.1 判断：不学，只刷真题

自考 Java 考的是**语言本身**：语法、面向对象、字符串、集合、异常、IO、多线程基础。**不考 Spring、不考框架、不考 JVM 调优。** 你是 Java 后端，这些全过。

唯一生疏的可能：GUI（Swing/AWT）和 Applet 这类早被淘汰的东西，值几分，认了。

### 2.2 章节框架（拿到教材后校一次）

1. Java 语言概述（平台无关性、JDK/JRE/JVM）
2. 数据类型与运算
3. 流程控制
4. 数组与字符串
5. 类与对象（构造、重载、this、static、包）
6. 继承与多态（重写 vs 重载、abstract、interface）
7. 异常处理（try-catch-finally、throws、自定义异常）
8. 常用类库（String/StringBuilder、Math、包装类、日期）
9. 集合框架（List/Set/Map 接口与实现类差异）
10. 输入输出流（字节流/字符流、包装流、序列化）
11. 多线程（Thread/Runnable、同步、线程状态）
12. GUI 与事件处理（了解即可）

### 2.3 做法（总计 5–8 小时）

- 找 5 套近年真题，**直接做，不预习**
- 错了才回书查，只查错的那一点
- 重点补两个盲区：**集合框架的接口层次** 和 **IO 流类名**（这两块靠记忆，容易失分）
- 2026-12 一次性做完，不拆周

## 3. 数据结构与算法（13003）

### 3.1 章节框架（按主流大纲，拿到教材校一次）

1. 绪论（数据结构基本概念、**时间/空间复杂度**）
2. 线性表（顺序表、单链表、双向链表、循环链表）
3. 栈和队列（顺序/链式、应用：括号匹配、表达式求值、递归）
4. 串与数组（模式匹配、稀疏矩阵）
5. 树与二叉树（**二叉树遍历**、线索树、哈夫曼树、**二叉排序树**、平衡树概念）
6. 图（存储结构、**DFS/BFS**、最小生成树、最短路径、拓扑排序）
7. 查找（顺序/折半/分块、**哈希表**与冲突处理）
8. 排序（插入、冒泡、**快速排序**、选择、归并、堆排序、基数排序 + 稳定性与复杂度对比）

### 3.2 必须能手写的八个算法

这是本科目的命门，光看会忘：

1. 顺序表按位插入 / 删除
2. 单链表头插法建表 + 就地逆置
3. 二叉树前中后序递归遍历 + 层次遍历（队列）
4. 二叉排序树的插入与查找
5. 折半查找
6. 快速排序（会画每一趟结果）
7. 归并排序（会画合并过程）
8. 哈希表构造（除留余数法）+ 线性探测

### 3.3 复杂度分析

每写完一个算法，都要标出最好/最坏/平均时间复杂度和空间复杂度。这部分选择题必考，且是唯一能靠"背表格"稳拿的分。

### 3.4 时间线

| 时间 | 内容 | 强度 |
|---|---|---|
| 2026-12 | 第 1–3 章（线性表、栈队列） | 2h/周 |
| 2027-01 ~ 02 | 第 4–6 章（树、图） | 2h/周 |
| 2027-03 | 第 7–8 章（查找、排序）+ 手写算法二轮 | 4h/周 |
| 2027-03-25 ~ 04-10 | 真题 + 手写算法默写 | 冲刺 |

## 4. 软件工程（13005）

### 4.1 判断：纯背诵，3 月突击

这门课几乎没有需要动脑的地方，全是概念、模型、术语、图。**现在碰它是最浪费的用法**——背了到 4 月也忘。

### 4.2 章节框架（拿到教材后校一次）

1. 软件工程概述（软件危机的表现、软件工程的定义与三要素）
2. 软件过程模型（瀑布、原型、增量、螺旋、敏捷——**每种的优缺点与适用场景**）
3. 可行性研究与需求分析（需求分类、数据流图 DFD、数据字典）
4. 结构化设计（模块化、**耦合与内聚的七种类型及排序**、结构图）
5. 面向对象分析与设计（UML 类图、用例图、顺序图）
6. 软件实现与测试（**黑盒/白盒、等价类划分、边界值、语句覆盖/判定覆盖**、测试阶段划分）
7. 软件维护（四种维护类型及占比）
8. 软件项目管理（进度：甘特图/PERT、成本估算、质量保证、CMM）

### 4.3 做法（2 周，每天 1h）

- 第一遍：按章读，只画线不做笔记
- 第二遍：**背 30 个核心术语**
- 第三遍：做真题，重点练**耦合内聚排序**和**测试用例设计**这两类必考大题

核心 30 术语：软件危机、软件生命周期、瀑布模型、原型模型、螺旋模型、增量模型、敏捷、需求分析、数据流图、数据字典、模块化、耦合、内聚、抽象、信息隐蔽、结构化设计、面向对象、UML、类图、用例图、黑盒测试、白盒测试、等价类划分、边界值分析、语句覆盖、判定覆盖、单元测试、集成测试、确认测试、软件维护。
