# 全局作战计划（`38h/周` 早起版 · 2026-11-23 定稿）

## 0. 核心定调与真实约束

- **四大目标闭环**：
  1. **2027-03 ~ 04 换工作（P0 生存线）**：主攻 **上海 AI Agent 应用开发 / AI 后端工程师**，用 **5 年 Java 后端经验托底** + **工业级线上 Agent Demo 绕过 HR 学历初筛直聊技术主管**，确保金三银四离开消耗精力的现岗位。
  2. **2027-03-20 PETS-3 冲高分（75–80+）**：按**基础水平起步**，给足 **~160 小时**慢学冗余；拿高分心理有底 + 免考自考 `13000`（7 学分）+ 给雅思高分与考研英二打地基。
  3. **2027-04-10 自考四科全过（13 学分）**：`C++ 04737` / `Java 13215` / `数据结构 13003` / `软件工程 13005` 一门不砍，按 **1.4 倍慢学冗余给足 ~290 小时**；同时保留 **2 月底网报前安全阀**（达标全报，极端加班则精准保过）。
  4. **中长期跃迁（2027-05 起）**：4 月自考完冲 **雅思高分** → 报 4 门实践 + 办免考/转换 → 下半年借 `302 数二 + 408` 顺带收尾 10 月自考并冲 **复旦 305 学院 `085400 电子信息`（专硕：101 + 204 英二 + 302 数二 + 408；8 门成绩单复试阶段核验）**。
- **已考完出清**：`2026-11-22` 人工智能训练师（三级）等 12 月下旬出成绩，现阶段 **0 分钟投入**。

### 专门治“学得慢、效率没那么高”的三条铁律
1. **只记「45 分钟专注块」，不记坐书桌时长**：手机放客厅或开免打扰，专注 45min 休 5–10min，每周盯死 **50 个专注块**。
2. **永远「先看考题/面试题，再翻书」**：不逐字通读 350 页教材；例题亲手敲通 + 做对应真题，卡壳再回查。
3. **每晚 `22:00` 关机前 2 分钟闭眼复述**：说出今晚装进脑子、考试/面试能直接拿分的 1–2 个点，防“当时懂、下周忘”。

## 4. 自考四科执行细则（2027-04，13 学分）

### 4.1 C++ 程序设计（04737，~150h 慢学冗余）

- 闭卷笔试 150 分钟：**识记 20% + 领会 35% + 简单应用 30% + 综合应用 15%**（55% 概念与读代码，~40 分写代码）。
- **九章核心与页码**（辛运帏 2019 版）：
  - ch1 语言简介（29–56，低）｜ ch2 面向对象概念（61–90，中）｜ **ch3 类和对象进阶（91–149，最高：构造/析构/拷贝构造/常成员常引用/this/静态/友元/封闭类）**
  - ch4 运算符重载（150–176，高）｜ **ch5 继承与派生（177–243，最高）** ｜ **ch6 多态与虚函数（244–275，最高）**
  - ch7 IO 流（276–301，中）｜ ch8 文件操作（302–328，中）｜ ch9 模板与 STL 认知（329–352，高）
- **硬自检卡**：
  - [ ] 闭卷默写带构造、析构、拷贝构造、常成员的类；说清必须写拷贝构造的三种场景
  - [ ] 闭卷写虚函数多态，说清多态三条件与虚析构
  - [ ] 闭卷重载 `+` 与 `<<`（区分成员/非成员）；写函数模板与类模板各一个
  - [ ] 2023–2025 共 6 套真题 150 分钟限时稳定 **≥70 分**

### 4.2 Java（13215）/ 数据结构（13003）/ 软件工程（13005）

- **Java（13215，~15–20h）**：W1–W3 刷 5 套真题稳 ≥75 封存；重点补**集合框架接口层次**和**IO 流类名**。
- **数据结构（13003，~70h，与面试算法 + 408 合一）**：必会闭卷手写八大算法（顺序表增删、单链表头插与就地逆置、二叉树递归与层次遍历、BST 插入查找、折半查找、快排、归并、哈希除留余数+线性探测）+ 全部时空复杂度对比表。
- **软件工程（13005，~40h）**：3 月突击——画线通读 → 背 **30 核心术语** → 专攻**耦合内聚 7 种排序**与**等价类/边界值/覆盖率测试用例大题** + 5 套整卷。
  - 核心 30 术语：软件危机、软件生命周期、瀑布模型、原型模型、螺旋模型、增量模型、敏捷、需求分析、数据流图、数据字典、模块化、耦合、内聚、抽象、信息隐蔽、结构化设计、面向对象、UML、类图、用例图、黑盒测试、白盒测试、等价类划分、边界值分析、语句覆盖、判定覆盖、单元测试、集成测试、确认测试、软件维护。
