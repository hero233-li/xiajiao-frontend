## 五阶段的门与失败分支
1. 短诊断：先做01学生卷，每科25分钟，到时停。复用上述高数已暴露题型与离散纯真值，不重复旧题；新题跨其他章。每题写方法、步骤、用时、看答案情况。交卷后按“不会方法 / 计算 / 漏问 / 时间 / 识别缺页”分类，即结束诊断，不设总分通过门。未覆盖内容仍为未测。卡住90秒先跳过，不补时。
2. 小题型学习：从诊断中选每科1个可在40-50分钟完成的基础任务。固定结构为识别与前置、完整例题、渐退提示、两题独立（至少一道换设问）、方法卡。本轮仅生成高数平面距离45分钟块。其余块收到作答后再生成。两独立题关键步骤都正确、无提示且不漏问，记独立能做，转到下一题型；失败只修1-3处。45分钟仍不会则检查前置，缩成5-10分钟任务或暂缓。高数第一章首轮总修补最多60-90分钟，之后必须到其他章。
3. 隔天复测：只对前一天“独立能做”的题型，10-15分钟做未见同类题，题面不写方法名。全部关键步骤正确才标“隔天复测通过”；失败按错误局部补5-10分钟，再安排新题，不整章返工。周五晚新学题型无充分隔天窗口时如实标“独立能做，未隔天验证”。
4. 跨章限时：某科至少两个不同章节题型达到独立能做后，安排30-50分钟混排卷，题号不按方法分组，不提前给公式。检查识别、计算、漏问、时间；失误只回对应题型。不要求100分卷。若仅一个题型能做，把混排块缩成20分钟识别+基础练习，保留其他科时间。
5. 真题验证：优先查验本机原PDF的页头课程代码、日期、完整页数、范围与改版差异。只有未看答案、闭卷、按规定时限完成的整套原始真题才用于整卷表现判断。尚未满足或剩余时间不足150分钟加批改余量，就选30-40分钟带“来源文件、页码、题号、是否改编”标识的真题选题；不得外推整卷预测分。当前未将目录文件名当作已认证来源，不分发未核范围的02198作13175验证。至周五晚/周六晚以方法卡、典型错因、基础题收束，不扩难题。
